# Current Tasks

## Active Task

Use HelloLaunch to guide a new project from intake to reviewed project brief before coding.

## Required Flow

1. Ask project intake questions one section at a time.
2. Summarize answers into PROJECT-BRIEF.md.
3. Stop and ask the user to review.
4. Revise the brief if needed.
5. Wait for user approval before coding.
6. Generate project-specific docs after approval.
7. Generate starter app files only after docs are reviewed.

## Expected First Output

```txt
PROJECT-BRIEF.md
```

No code should be generated before the project brief is reviewed.
